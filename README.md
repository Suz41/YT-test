# YouTube Mobile UI Mockup

A pixel-perfect, responsive HTML & CSS clone of the YouTube mobile player description bottom sheet UI.

## Features
- **Authentic YouTube Dark Theme**: Accurate dark palette, typography, and layout.
- **Dynamic Stats Grid**: Displays Likes, Views, and Date metadata.
- **Click-to-Change Thumbnail**: Click on the video frame to dynamically upload and preview any custom image in real-time.
- **16:9 Aspect Ratio**: Enforced 16:9 video player frame.

## Tech Stack
- HTML5
- CSS3 (Vanilla CSS)
- JavaScript (File API for dynamic image swapping)
- Node.js (Static hosting)
